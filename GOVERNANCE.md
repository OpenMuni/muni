# Project stewardship

Muni.fyi is maintained by Charles Magnarelli. The source project welcomes contributions from
residents, civic groups, researchers, designers, accessibility advocates, and
developers. You do not need to run a city data system to help make one clearer.

Anyone can propose a source, interface change, correction, or documentation
improvement through an issue or pull request. Maintainers set the release
schedule and merge changes after reviewing their accuracy, privacy,
accessibility, upkeep cost, and fit with Muni's purpose. For consequential
changes, the issue or pull request should record the evidence and decision so
others can understand or challenge it later. We especially welcome feedback
from people in the communities represented by the data.

The public repository is the place to discuss the software and its methods.
It does not give contributors access to production accounts or residents'
submissions. The Muni.fyi operator remains responsible for the running service and responding
to private security and personal-data reports. See [CONTRIBUTING.md](CONTRIBUTING.md)
for the contribution workflow and [SECURITY.md](SECURITY.md) for private reports.
